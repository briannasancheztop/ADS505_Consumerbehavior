Programming Language: Python

Dataset: Consumer Behavior and Shopping Habits Dataset

Project Overview

Problem Statement

Retailers are experiencing declining foot traffic as customers shift more into online shopping. This shift threatens profitability and long-term viability. To remain competitive, companies must adapt to evolving consumer preferences by integrating stronger omnichannel strategies.

Business Objective

This project develops a predictive model to identify high-value customers (top 25% by purchase amount) in a retail shopping behavior dataset. The goal is to enable targeted marketing strategies, optimize resource allocation, improve customer retention, and increase overall revenue.
Dataset Description

Source: Kaggle

Size: 3,900 rows × 18 columns
Variables: Customer ID, Age, Gender, Item Purchased, Category, Purchase Amount (USD), Location, Size, Color, Season, Review Rating, Subscription Status, Shipping Type, Discount Applied, Promo Code Used, Previous Purchases, Payment Method, Frequency of Purchases

Key Findings

Online Dominates

83% of revenue is online; only 17% in-store
~$60/order across both channels (identical spending)
All age groups prefer online (80%+ of purchases)

Conclusion:

All customers behave similarly (~$60/order, 80%+ online).
